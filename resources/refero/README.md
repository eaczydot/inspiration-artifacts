# Refero design research

Standing workflow for every new inspiration:

1. Search Refero first for an exact company/product match.
2. If present, cite the style URL and use its role-based tokens and constraints as one source, then validate against the live product/site and screen-level evidence.
3. If absent, say `Refero exact match: not found` with the check date and infer the same schema from primary sources.
4. Never bulk mirror Refero's gallery, screenshots, or dataset. Store attribution and distilled design findings only. Refero's terms permit ordinary product-design work from the insights, but prohibit bulk extraction, redistribution, competing datasets, and model training/evaluation.

Required DESIGN.md sections: provenance and Refero check; north star and theme; color tokens; typography and type scale; spacing, sizing and radii; layout and responsive behavior; elevation and borders; component treatments; imagery/motion; do/don't rules; library/component mapping; known inference limits.
