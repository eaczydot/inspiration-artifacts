# Inspiration Artifacts
Built from Vercel's official `with-storybook` Next.js example. Each inspiration source has its own pages and components tree:

- `src/inspirations/monaco/{pages,components}`
- `src/inspirations/shadcncraft/{pages,components}`
- `src/inspirations/brutalist-icons/{pages,components}`
- `src/inspirations/opensourceui/{pages,components}`

The first story is **Inspiration / Monaco / Pages / Accounts Table**: a dense dark account table with semantic badges, row selection, and interactive score reasoning/source popovers.

```bash
npm install
npm run dev
npm run storybook
npm run build
npm run build-storybook
```
No API keys or backend required. Mock data is local; prototype source URLs are placeholders.
